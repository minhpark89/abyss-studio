Quản lý kênh YouTube

Đang đọc báo cáo…

Nhận xét từ số liệu

    Kết nối kênh

    File OAuth và hướng dẫn thiết lập
    1. Trong cùng một dự án Google Cloud, bật YouTube Data API v3, YouTube Analytics API và YouTube Reporting API.
    2. Trong Google Auth Platform, điền Branding và chọn Audience. Với dự án External ở chế độ Testing, thêm từng email cần dùng vào Test users. Tại Data Access, thêm hai scope youtube.readonly và yt-analytics.readonly.
    3. Ở Clients, chọn Create client → Desktop app. Tải JSON rồi nhập ở bên dưới.
    4. Dùng một file JSON cho các kênh trên PC. Mỗi lần thêm kênh, chọn đúng kênh cá nhân hoặc kênh thương hiệu trên Google và xác nhận. Lần đồng bộ đầu sẽ đăng ký báo cáo Reach nếu kênh hỗ trợ.

    Khóa được mã hóa theo tài khoản Windows. Quản lý quyền đã cấp tại Tài khoản Google.

    vidIQ MCP cho kênh đang xem

    Lấy API key chỉ đọc của vidIQ. Khi bật, mỗi ngày app sẽ yêu cầu thống kê tăng trưởng công khai 7 ngày của kênh một lần. Yêu cầu này dùng credit trong gói vidIQ.
